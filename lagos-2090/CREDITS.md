# Credits — Lagos 2090 starter pack (Blender + Unreal Engine 5)

Every file in this pack is freely licensed. Most are **CC0 1.0** (public domain, attribution appreciated but not required). A few models are **CC-BY 3.0** (attribution required). The title font is **SIL Open Font License 1.1**.

This is the lean pack. Kenney and other self-contained models, the font and the docs are bundled. The 4K textures, HDRIs and high-detail Poly Haven models listed below are **not** inside the zip — run `fetch-assets.ps1` or `fetch_assets.py` to download them from the same original sources into the paths shown here.

Each model is provided as the original `.glb` / `.gltf` plus an Unreal-ready `.fbx` (centimetre scale, Z-up, pivot at the base). Paths below name the source file; the `.fbx` sits beside it, or inside the same `hd-*` folder for high-detail Poly Haven assets. Converting to FBX does not change the licence.

If you post the video, please credit the CC-BY authors below. Crediting the CC0 authors (Kenney, Quaternius, Poly Haven, ambientCG) is appreciated.

Quixel Megascans / Fab assets are **not** in this pack. They are free to use inside UE5 and must be credited if you add them in the project.
